# כדור בדולח

אפליקציית בידור מיסטית בעברית: כדור בדולח אינטראקטיבי, ולשונית "גילויים" עם עולם שלם של קריאות:

- קלף היום ופריסת שלושה קלפים (22 קלפי ארקנה)
- מזלות (12 מזלות, הורוסקופ יומי) ונומרולוגיה (גימטריה אמיתית עם אותיות סופיות)
- **קריאת כף יד** מודרכת (קווים, צורת היד וגבעות) וקריאה שמורכבת מהבחירות שלכם. לא מנתחת תמונה
- **אסטרולוגיה סינית** לפי טבלת ראש השנה הסיני 1924–2043, יסוד, שעה סינית, התאמות ותחזית לשנה הנוכחית
- **התאמה זוגית** (מזל, אסטרולוגיה סינית ונומרולוגיה)
- **קריאה בקפה** (40 סמלים ומיקומים)
- **פתרון חלומות** (מילון של 123 סמלים וזיהוי חופשי בטקסט)
- **אי צ'ינג** (64 הקסגרמות, הטלת שלושה מטבעות)
- **מספרי מלאכים ושעות כפולות**
- יומן קריאות אישי (נשמר בדפדפן בלבד)

דף אחד (`index.html`), בלי build ובלי תלויות. הנתונים נשמרים בדפדפן בלבד (`localStorage`, מפתחות `kadur_*`).
כל הקריאות נוצרות מקומית ומיועדות לבידור בלבד. הטקסטים נכתבו מחדש ואינם תרגום של מקור קלאסי. בטקסטי שורות משתנות באי צ'ינג יש טקסט כללי לפי מיקום השורה ולא הטקסטים הקלאסיים.

## הרצה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח http://localhost:8000

## פריסה

### Firebase Hosting
1. פרויקט Firebase: `kad-ball` (מוגדר ב-`.firebaserc` וב-workflow).
2. `firebase deploy --only hosting`
3. פריסה אוטומטית ב-push ל-`main`: להריץ פעם אחת `firebase init hosting:github` (יוצר את הסוד `FIREBASE_SERVICE_ACCOUNT`). בלי הסוד ה-workflow מדלג ולא נכשל.

### Vercel
לייבא את הריפו ב-vercel.com/new. זה אתר סטטי, אז אין צורך ב-Framework, Build Command או Output Directory (`vercel.json` כבר קיים).

## הטמעה
האפליקציה נפתחת גם בתוך ה-CRM (כפתור "← CRM" מופיע רק בתוך iframe). הגרסה המתארחת ב-CRM נמצאת ב-`hen27e-alt/crm-fix` בנתיב `/kadur/`.
